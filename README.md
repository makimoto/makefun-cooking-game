**Umami Rush — Midnight Ramen Stand.** A 90-second cooking game in the browser: work a lantern-lit ramen stall through the night rush. Read the order board, ladle the right broth (shoyu, miso or tonkotsu), boil the noodles and pull them inside each ticket's doneness zone — firm, regular or soft — then plate every topping the ticket asks for and ring the bell. Perfect bowls build a scoring combo; dawdle and your customers walk out hungry. Played with mouse and keyboard, no network, no build step.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

To hand the game in the way the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
